# ビトニックソートの並列化実装レポート

## 1. 概要

本レポートでは、OpenMPを使用したビトニックソートの並列化実装について詳しく解説する。ビトニックソートは並列処理に適したソートアルゴリズムであり、本実装では大規模データセット（1,048,576要素）に対して効率的な並列化を実現している。

## 2. ビトニックソートアルゴリズムの原理

### 2.1 ビトニックシーケンス
ビトニックシーケンスとは、単調増加後に単調減少する、または単調減少後に単調増加する数列のことである。

例：
- [1, 3, 5, 7, 6, 4, 2, 0] （増加→減少）
- [7, 5, 3, 1, 2, 4, 6, 8] （減少→増加）

### 2.2 アルゴリズムの基本概念
ビトニックソートは以下の手順で動作する：

1. **ビトニックシーケンスの構築**: 入力データをビトニックシーケンスに変換
2. **ビトニックマージ**: ビトニックシーケンスをソート済みシーケンスに変換

### 2.3 並列化適性
ビトニックソートは以下の理由で並列化に適している：
- 比較・交換操作が独立して実行可能
- データ依存関係が少ない
- 段階的な処理により並列度が高い

## 3. プログラムの詳細解説

### 3.1 データ構造と定数

```c
#define SHIFTSIZE 20
#define V_SIZE (1LL << SHIFTSIZE)  // 1,048,576要素

long long *v;  // グローバル配列
```

- **SHIFTSIZE**: データサイズを2の累乗で定義（20 = 1,048,576要素）
- **V_SIZE**: 実際の配列サイズ
- **v**: ソート対象のグローバル配列

### 3.2 初期化関数

```c
void randomize(long long seed) {
    srand(seed);
    for (long long i = 0; i < V_SIZE; ++i) {
        v[i] = rand();
    }
}
```

- 配列をランダムな値で初期化
- 再現性のため固定シードを使用

### 3.3 交換関数

```c
void swap(long long *a, long long *b) {
    long long tmp = *a;
    *a = *b;
    *b = tmp;
}
```

- 2つの要素を交換する基本的な関数
- ポインタを使用して効率的に実装

### 3.4 核心部分：並列化された交換処理

```c
void swapping(long long i, long long j) {
    long long swap_distance = 1LL << (i - j);

    #pragma omp parallel for
    for (long long v_i = 0; v_i < V_SIZE / 2; ++v_i) {
        long long low = v_i & (swap_distance - 1);
        long long swap_pos = (v_i << 1) - low;
        int is_upper = (swap_pos & (2LL << i)) == 0;

        long long idx1 = swap_pos;
        long long idx2 = swap_pos | swap_distance;

        if ((v[idx1] > v[idx2]) == is_upper) {
            swap(&v[idx1], &v[idx2]);
        }
    }
}
```

#### 3.4.1 並列化の実装詳細

**OpenMPディレクティブ**
```c
#pragma omp parallel for
```
- ループを自動的に並列化
- 利用可能なCPUコア数に応じてスレッドを生成
- 各スレッドが独立したイテレーションを処理

**インデックス計算の工夫**
```c
long long swap_distance = 1LL << (i - j);
long long low = v_i & (swap_distance - 1);
long long swap_pos = (v_i << 1) - low;
```

- **swap_distance**: 比較する要素間の距離を計算
- **low**: ビットマスクを使用した効率的な計算
- **swap_pos**: 実際の配列インデックスを計算

**比較ペアの決定**
```c
long long idx1 = swap_pos;
long long idx2 = swap_pos | swap_distance;
int is_upper = (swap_pos & (2LL << i)) == 0;
```

- **idx1, idx2**: 比較・交換する要素のインデックス
- **is_upper**: 上段か下段かを判定するフラグ

**条件付き交換**
```c
if ((v[idx1] > v[idx2]) == is_upper) {
    swap(&v[idx1], &v[idx2]);
}
```

- ビトニックソートの特性に基づく条件付き交換
- 並列実行時にデータ競合が発生しない設計

### 3.5 ビトニックソートのメイン処理

```c
void bitonic_sort() {
    long long log_vsize = log2(V_SIZE);
    for (long long i = 0; i < log_vsize; ++i) {
        for (long long j = 0; j <= i; ++j) {
            swapping(i, j);
        }
    }
}
```

- **外側ループ**: ビトニックシーケンスの構築段階
- **内側ループ**: 各段階での並列交換処理
- **log_vsize**: 配列サイズの対数（20回の反復）

## 4. 並列化の詳細分析

### 4.1 並列化戦略

**データ並列化**
- 配列の異なる部分を複数のスレッドで同時処理
- 各スレッドが独立した比較・交換ペアを担当

**粒度の最適化**
- ループレベルでの並列化
- 十分な並列度を確保（V_SIZE/2 = 524,288個のタスク）

### 4.2 データ依存関係の解決

**独立性の確保**
- 各イテレーションで異なるインデックスペアを処理
- ビトニックソートの特性により、同時実行可能

**同期の最小化**
- 明示的な同期処理が不要
- OpenMPが自動的にスレッド管理

### 4.3 メモリアクセスパターン

**局所性の考慮**
- 予測可能なアクセスパターン
- キャッシュ効率を考慮した設計

**競合の回避**
- 各スレッドが異なるメモリ領域にアクセス
- データ競合の発生を防止
